1. **新增 Responses API 模型接入**
   - 可以设置接口地址、API 密钥和模型名称。
   - 支持文本与图片消息，保留豆包、DeepSeek、Ollama 接入。
2. **升级长期记忆系统**
   - 使用“重要事实＋历史摘要＋近期对话”组织上下文。
   - 完整聊天记录保存在本地，早期对话在后台压缩成摘要。
   - 移除固定消息条数导致的对话限制。
3. **新增重要记忆管理（实验性）**
   - 支持通过“请记住……”和“忘掉……”管理事实。
   - 可在后台提取长期偏好、身份、目标等信息。
   - 设置窗口新增“管理重要记忆”，支持查看、添加、修改和删除。
4. **优化语音生成与连续播放**
   - 日语生成到完整句子后即可开始合成。
   - 长回复分段处理，最多同时生成两段音频（可能需要开会员）。
   - 按顺序播放，并提前连接、准备下一段音频。
   - 新一轮回复会清理旧队列，忽略上一轮迟到的音频。
5. **调整 Vocu 配置**
   - 新增独立的“实时流优先”选项。
   - 实时接口失败后可回退到任务接口。
   - 支持 `market:` 格式的音色 ID。
   - 复用网络连接，提前预热，减少连接等待。
6. **改进预设语音触发**
   - 开启 AI 语音模式后，也能按设置概率使用预设语音。
   - 只有一个匹配候选时直接使用，省去模型选择步骤
